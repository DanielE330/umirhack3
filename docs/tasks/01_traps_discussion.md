# 🪤 Обсуждение: Какие ловушки мы можем реализовать

Исходя из задачи создать реалистичные приманки (FR-A1, MASK-6), вот какие ловушки я предлагаю для хакатона:

## 1. Уровень Low-interaction (Минимум риска)
* **Что делает:** Просто "слушает" порты. Если хакер стучится на порт, он записывает его IP и сразу закрывает соединение.
* **Идея для реализации:** `Port Scan Trap`. Открываем сразу 100 портов (21, 22, 23, 80, 443, 3306 и т.д.).
* **Смысл:** Работает как радар. Моментально детектирует автоматические сканеры (Nmap, Masscan) и сообщает бэкенду.

## 2. Уровень Medium-interaction (Золотая середина для демо)
*Здесь хакер взаимодействует с логикой, но реальной системы нет.*

* **Ловушка 2.1: Fake-SSH (Cowrie)**
  * **Описание:** Имитирует консоль Linux. Хакер заходит, вводит пароль, пишет `ls`, `wget`.
  * **Зачем:** Идеально для сбора паролей (брутфорс) и вредоносных скриптов, которые хакер пытается скачать.
  
* **Ловушка 2.2: Fake-HTTP (Админка роутера или WordPress)**
  * **Описание:** Поднимаем фейковую страницу `/wp-admin` или веб-интерфейс роутера.
  * **Зачем:** Хакерам очень нравится ломать веб-админки. Мы соберем словари паролей, которые они используют для подбора.

* **Ловушка 2.3: Fake-Redis / Fake-MySQL**
  * **Описание:** База данных без пароля.
  * **Зачем:** Боты постоянно ищут открытые базы данных, чтобы стереть их и оставить сообщение с требованием выкупа (Ransomware). Мы запишем их биткоин-кошельки.

## 3. Уровень High-interaction (Proxmox - Требование техлида)
*Здесь хакер получает реальный доступ к виртуальной машине.*

* **Ловушка 3.1: Уязвимый Linux-сервер (Proxmox VM)**
  * **Описание:** Настоящая виртуальная машина Ubuntu (1 Core, 10GB RAM, 10GB Disk), развернутая нашим скриптом `proxmox_manager.py`. На ней специально оставлен старый уязвимый софт (например, старая версия Sudo или Exim).
  * **Зачем:** Позволяет ИИ (Hermes) анализировать поведение продвинутых хакеров. Мы отслеживаем абсолютно все системные вызовы внутри виртуалки.
  * **Риски:** Нужна строгая изоляция (VLAN), чтобы хакер не выпрыгнул из виртуалки на наш сервер `100.64.0.30`.
