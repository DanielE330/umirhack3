# 📋 Актуальный Roadmap и задачи HoneyForge

## 1. 🤖 Аутентификация Telegram с аккаунтами сервера (Multi-admin Telegram SOC)
* [x] **Привязка Telegram к пользователю платформы:**
  * Добавить в модель `User` поля `telegram_chat_id`, `telegram_username`, `telegram_link_code`, `telegram_link_expires`.
  * Эндпоинт `POST /api/auth/me/telegram/code` — генерация одноразового 6-значного кода привязки (например, `HF-123456`) и deep-link ссылки (`t.me/Bot?start=HF-123456`).
  * Кнопка и модальное окно «Подключить Telegram» в интерфейсе оператора.
* [x] **Обработка команд в Telegram-боте:**
  * Поддержка `/start <код>` и `/link <код>` для мгновенной безопасной авторизации.
  * Команды `/status` (проверка прав и роли), `/unlink` (отвязка аккаунта).
* [x] **Разграничение прав и таргетированные алерты:**
  * Проверка прав при нажатии кнопок (например, «❌ Заблокировать IP»): блокировать IP могут только авторизованные администраторы и операторы платформы.
  * Рассылка алертов всем активным привязанным администраторам/операторам, а не в один статичный чат.
  * Фиксация автора блокировки в истории и в Telegram-сообщении (`Заблокировал: @username`).

## 2. 🪤 Новые типы ловушек и углубление эмуляции
* [x] **Продвинутый fake-SSH (`agent/netsvc/traps/ssh.py`):**
  * Поддержка цепочек команд (`cd /tmp && wget ... && ./payload`, разбор `;`, `&&`, `|`).
  * Эмуляция загрузки файлов (`wget`, `curl`) — симуляция успешного скачивания вредоносов с логированием URL полезной нагрузки.
  * Расширение honeytoken-файлов (`id_rsa`, `.env`, `passwords.txt`).
* [x] **Fake-HTTP веб-ловушки (`agent/netsvc/traps/http.py`):**
  * Реалистичные панели входа: `/wp-admin`, роутер/MikroTik, phpMyAdmin.
  * Сбор словарей логинов и паролей атакующих.
* [x] **Fake-БД (Low/Medium):**
  * Fake-Redis / Fake-FTP интерактивные эмуляторы в `banner.py` для перехвата ботов и ransomware.
