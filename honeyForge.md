# 🍯 HoneyForge — Продуктовая стратегия и позиционирование

В рамках защиты проекта на хакатоне продукт разделяется на два сегмента (Tier 1 и Tier 2). Это демонстрирует масштабируемость бизнес-модели и закрывает потребности разных аудиторий.

---

## 🎯 Версия 1: «HoneyForge Standard» (MVP для хакатона)
**Сегмент:** B2C, Малый и средний бизнес (SMB).  
**Аудитория:** Разработчики, DevOps-инженеры, владельцы небольших проектов, VPS и интернет-магазинов. Пользователи без собственных ИБ-отделов.

* **Технология:** **Docker** (через Docker SDK).
* **Уровень ловушек:** Low-interaction & Medium-interaction (например, Cowrie).
* **Развертывание:** Plug & Play (Установка в одну команду). Работает на любом дешевом облачном VPS.
* **Сценарий использования:** Быстрое развертывание защиты. Ловушки отвлекают ботов, собирают базовую аналитику (логины, пароли, команды), а бэкенд блокирует IP-адреса брутфорсеров.

> **Статус для хакатона:** Это **MVP (Minimum Viable Product)**. Именно эта версия реализуется в коде и показывается вживую (демо, сбор логов, алерт в Telegram).

---

## 🛡️ Версия 2: «HoneyForge Enterprise» (Premium / Roadmap)
**Сегмент:** B2B, Корпорации.  
**Аудитория:** Крупный бизнес, банки, SOC (Security Operations Center), корпоративные ИБ-отделы с собственной bare-metal инфраструктурой.

* **Технология:** Интеграция напрямую в гипервизор **Proxmox** (через Proxmox API / `proxmoxer`).
* **Уровень ловушек:** High-interaction (полноценные изолированные виртуальные машины / клоны шаблонов ОС).
* **Развертывание:** On-premise. Требует предварительной настройки инфраструктуры клиента.
* **Сценарий использования:** Глубокий анализ угроз нулевого дня (Zero-day) и сложного вредоносного ПО (Malware). Платформа динамически разворачивает полноценные уязвимые серверы, позволяет хакерам "захватить" их, а ИИ (Hermes) анализирует поведение вирусов без риска для основной сети.

> **Статус для хакатона:** Это **Product Roadmap / Premium Feature**. На защите представляется на слайдах архитектуры как готовое к масштабированию решение для крупного бизнеса.

---

## 💡 Стратегия защиты проекта (Питч)

1. **Проблема:** "Малый бизнес не может позволить себе сложные системы защиты, а корпоративным энтерпрайзам нужны безопасные песочницы для анализа сложных вирусов."
2. **Решение:** "Мы создали HoneyForge — платформу для управления ловушками. Для захвата рынка мы сделали версию Standard на базе Docker, которая ставится одной командой на любой сервер. А для корпоративного сектора у нас спроектирована архитектура Enterprise на базе Proxmox."
3. **Демонстрация:** Демонстрируется работа версии Standard (Docker), которая доказывает работоспособность ядра системы, сбор логов и анализ с помощью ИИ.
