# 🛡️ Типы ловушек (Honeypots) для интеграции

В HoneyForge мы поддерживаем два уровня ловушек, которые можно разворачивать одной кнопкой.

## 1. Легкие ловушки (Low/Medium-interaction)
*Разворачиваются через Docker. Мгновенный запуск, полностью изолированы, легко собирать логи.*

* **Cowrie (SSH/Telnet):** Самая популярная ловушка в мире. Имитирует консоль Linux. Хакер думает, что взломал сервер, вводит команды, пытается скачать вирусы — а Cowrie заботливо записывает каждую его кнопку и сохраняет скачанные вирусы для анализа.
* **Dionaea (SMB, FTP, HTTP):** Специализируется на ловле "червей" и вирусов-вымогателей. Притворяется уязвимой Windows-шарой или сервером.
* **Snare / Glastopf (Web):** Притворяются уязвимыми веб-сайтами. Отлично собирают попытки SQL-инъекций и активность сканеров уязвимостей.
* **Wordpot:** Имитирует уязвимый WordPress. Собирает огромный объем спама и автоматических атак ботнетов.

## 2. Тяжелые ловушки (High-interaction)
*Разворачиваются через Proxmox API (LXC/QEMU). Настоящие операционные системы для продвинутых хакеров, которые распознают Docker.*

* **Windows RDP Honeypot:** Настоящая ОС Windows с открытым портом 3389 (RDP). Требует установки скрытого агента (Sysmon / Elastic Agent) внутри системы для отправки логов кликов и запущенных процессов нам на бэкенд.
* **Уязвимый Linux (Metasploitable):** Настоящий Linux с устаревшими версиями сервисов. Используется для отслеживания того, как хакер пытается закрепиться в системе и повысить права.

---
## 📌 План действий по ловушкам:
1. Выбрать одну Docker-ловушку для первого прототипа (идеальный кандидат — **Cowrie**).
2. Подготовить для нее Docker-шаблон, который будет запускать наш оркестратор.
3. Написать парсер, который будет читать JSON-логи из контейнера Cowrie и складывать их в нашу базу данных PostgreSQL.
